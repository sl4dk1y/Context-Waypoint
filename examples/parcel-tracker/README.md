# Parcel Tracker example

This fictional project illustrates a small, active Context Waypoint directory. It has a current objective, one durable constraint, one accepted decision, and an unfinished handoff. The records are intentionally short and contain no operational secrets.

Start with [`.context-waypoint/CURRENT.md`](.context-waypoint/CURRENT.md), then follow only the linked handoff and decision if the task concerns delivery status polling.
